# 作業指示書 00001 — Q&A確定内容の仕様反映と実装開始

発行日: 2026-10-08
対象: AI-Othello
実行担当: Claude Code

## 目的
回答済みの `QandA.md` 全22項目を確認して `SPEC.md` に反映し、`RequiredSpecifications.md` を正本としてAIオセロ対戦ツールの実装を進める。

## 作業内容
1. `RequiredSpecifications.md`、`SPEC.md`、`QandA.md`、`README.md` を読む。仕様の優先順位は正本 `RequiredSpecifications.md`、明示的に回答された `QandA.md`、`SPEC.md` の順とする。矛盾があれば勝手に無視せず結果報告に記す。
2. `QandA.md` の回答22項目を `SPEC.md` に反映し、反映済みの項目を `QandA.md` で「反映済」に変更する。特に反則は**1局でプレイヤーごとに累積10回で反則負け**とし、目的が無限ループ防止であることを明記する。合法手でカウンタをリセットしない。
3. Pythonオセロルールエンジンを実装する（初期盤面、UTF-8の`●〇□`、8方向反転、合法手、PASS、終局）。
4. モックCLIを用いた対局管理、反則・技術エラー区別、総当たり、先後交換、棋譜・ログ、CSV成績、停止・再開を実装する。範囲が大きい場合、まず3とそのテストを完成させ、未完了の4を結果に明記する。
5. `pytest` の自動テストを作成・実行し、実際に実行したテストだけを実行済みとして報告する。実CLIの呼び出しや課金テストは、ユーザーの明示的な許可なしに行わない。
6. 実装した範囲に合わせて`README.md`を更新する。

## 実装時の重要事項
- AIの着手判断に合法手一覧を渡さない。AIの回答は座標またはPASSのみ。
- AIの反則回答時は盤面不変・同じ手番で再試行。反則は各プレイヤーの1局累積10回で打ち切り。
- CLI起動失敗・タイムアウト等は技術エラーとして分離する。
- APIキー等の秘密情報をコミット・ログへ記録しない。
- 実装内容について、未実行テスト・未確認CLIを「動作確認済み」として報告しない。
