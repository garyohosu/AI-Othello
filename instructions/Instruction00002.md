# Instruction00002 — 実AI CLI接続の準備（課金なし）

発行日: 2026-10-08
担当: Claude Code
参照: RequiredSpecifications.md / SPEC.md / QandA.md / instructions/Result00001.md

## 目的
指示00001の実装結果を引き継ぎ、実AI CLIを安全に接続する直前まで整備する。**AIモデルへの問い合わせ・実対局・課金の可能性がある操作は実行しない。**

## 作業指示

1. **現状確認**: 既存実装とResult00001.mdを読む。既存のテスト結果を鵜呑みにせず、現在の作業環境でpytestを実行し、結果を記録する。既存の変更を破壊しない。
2. **名前衝突解消**: プロジェクト内の `statistics.py` を `game_statistics.py` 等へ変更し、参照箇所、import、テスト、README/SPECの該当説明を更新する。Python標準 `statistics` が通常どおりimportできることをテストする。
3. **CLI調査（モデル呼び出し禁止）**: Claude Code CLI、Codex CLI、Gemini CLI、利用可能ならGrok関連CLIの有無を確認する。実行してよいのは原則 `--help`、`--version`、`where`/`Get-Command` 等のローカル情報確認のみ。特に非対話実行、モデル指定、プロンプト入力、出力形式、ツール・ファイル操作制限、タイムアウトに関するオプションを確認する。コマンドを推測で動作済みと記録しない。**実際のAI問い合わせやAPI送信はしない。** CLIを勝手にインストール・更新しない。
4. **モデル設定**: 実際に確認できたCLI仕様に合わせて `config/models.example.yaml` とアダプタの設定方法を更新する。ローカル用 `config/models.yaml` が必要なら作成してよいが、認証情報を入れずGit管理対象から除外する。廉価モデル候補2種類のモデルIDが未確認なら「未確認」として例示し、架空の動作確認はしない。
5. **セキュリティ**: モデルへの着手プロンプトに対する任意コード実行・ファイル編集を抑止する設定を検証可能な範囲で整理する。抑止できないCLIは実大会対象から除外する方針。既存サンドボックス挙動を勝手に緩めない。
6. **WindowsのPermissionError対策確認**: Result00001.mdの情報を調べ、ファイル置換リトライの上限、間隔、例外処理、原子的更新の整合性を確認。再現できない場合は「原因未確定」と明記し、再発時にファイル名・操作・例外・試行回数を追跡できる安全なログを設ける（秘密情報は出さない）。
7. **テスト**: 既存テストと変更部分のテストを実際に実行。モックCLIの対局・大会・再開・反則累積10回が退行していないことを確認。CLIヘルプを見ただけなら実AI接続「動作確認済み」とは書かない。失敗や警告も報告。
8. **ドキュメント**: READMEに確認済みCLIの準備方法、未確認部分、実際のモデル呼び出し前の承認が必要である旨を追記する。必要に応じてSPECと整合させる。

## 明確な禁止事項
- 実AIモデルへのAPI/CLI問い合わせ、スモークテスト対局、課金の可能性があるコマンドの実行。
- 認証情報の読み出し・掲載・コミット。
- 仕様上の反則10回ルールの変更。
- 実行していないテストを成功として報告すること。

## 完了条件
- 名前衝突が解消され、標準ライブラリ `statistics` のimportが可能。
- 利用可能なCLIと確認済みオプションが整理される。
- 設定サンプルとドキュメントが実装に一致している。
- pytestの実行結果、変更ファイル、既知の未解決事項が記録される。
- 実AI呼び出し回数0件、課金を伴う操作0件。
